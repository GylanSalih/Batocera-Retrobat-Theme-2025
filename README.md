# RetroVerse (Black-2025)

Custom EmulationStation Theme für RetroBat / Batocera.

Basierend auf **Retrofix** von Jiggi ([Original](https://github.com/20GotoTen/es-theme-retrofix)), stark angepasst und erweitert.

## Installation

1. Ordner nach `emulationstation/.emulationstation/themes/Black-2025/` kopieren
2. In EmulationStation → UI Settings → Theme Set → **Black-2025** auswählen
3. Neu laden

## Features

- Mehrere Gamelist-Views: 2Row+Banner, Horizontal-Row, LeftGrid+RightInfo, Full Banner, Grid
- Anpassbares System-Carousel (Rotation / Statisch)
- Help-Icon-Subsets für PSX, SNES, Xbox, Switch, Arcade
- Optionale Hintergrundmusik (OGG)

## Struktur

- `theme.xml` — Haupt-Theme
- `_inc/xml/gamelistview/` — Verschiedene Listen-Ansichten
- `_inc/xml/systemcarousel/` — Carousel-Varianten
- `_art/` — Poster, Controller, Logos
- `_inc/assets/` — Fonts, Icons, Sounds
